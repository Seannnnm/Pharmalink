Our application is a medicine stock finder designed to help users quickly locate available inventory for specific medications. It allows users to search for essential medicines, view real-time stock levels at nearby pharmacies, and access store location details. This tool is built primarily for patients seeking hard-to-find prescriptions and pharmacy managers needing to check regional availability during shortages.

    **`Medicine`** — Actions: Search, View Stock Levels, View Prices, Compare Results
*   **`Pharmacy`** — Actions: List Nearby, View Details, Get Directions, Call
*   **`Reservation`** — Actions: Create Reservation, Input Patient Details
*   **`Payment`** — Actions: View Settings, Manage
